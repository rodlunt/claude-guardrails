## Session Discipline

- **Every project should have a session-end protocol.** Before ending a session: run tests, review changed code for quality issues, audit TODO/task tracking for drift, verify .gitignore covers sensitive files, and commit clean. Run `/session-end` to fire the generic user-scope command at `~/.claude/commands/session-end.md` (stack-detecting: Node, Python, Go, Rust, Hugo, Vite). **A project-scoped `.claude/commands/session-end.md` does NOT work.** User-scope commands shadow project-scope ones, so a same-name project override never loads. This was asserted here as fact and was wrong: one repo carried such an override that had been silently inert since 10 Jul 2026, every session-end there ran the generic protocol, and the repo documented the opposite. To tailor a repo, add a `.claude/session-end-extra.md` extension, which the generic command detects and executes first at Step -1. The failure mode is the usual one: the override file exists, so it looks live, and nothing anywhere reports that it never ran.
- **Code review before committing major changes.** Run `/code-review` on the working diff, or `security-review` when the change touches auth, secrets, input handling or network exposure. Don't self-certify large diffs.
- **E2E test coverage check.** Before running a test suite, audit whether existing tests actually cover the features changed this session. Stale tests that pass give false confidence. Write missing tests before declaring the suite green.
